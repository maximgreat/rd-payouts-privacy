Rank Daddy Payouts – Privacy

Rank Daddy Payouts is a private internal tool used only by the owners of the Rank Daddy YouTube channel. It is not offered to the public.

What it accesses

  • YouTube (read-only): the Rank Daddy channel's list of uploaded videos and their engaged-view counts from YouTube Analytics. It cannot upload, edit or delete anything.
  • Notion: one internal database and one page used to track editor payments.

What it does with the data

It writes each video's engaged-view count into the internal Notion database to calculate editor bonuses. Nothing else.

Sharing

No data is sold, shared with third parties, or used for advertising. Data is not collected from anyone other than the channel owners.

Removing access

The channel owner can revoke access at any time at myaccount.google.com/permissions.
